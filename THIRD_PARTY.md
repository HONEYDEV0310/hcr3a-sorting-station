# Third-party dependencies and references

Dependencies are installed separately; their source is not vendored in this snapshot.

- ROS 2 Jazzy / rclpy / rosidl / std_srvs: https://docs.ros.org/en/jazzy/
- Eclipse Cyclone DDS and its ROS middleware: https://github.com/eclipse-cyclonedds/cyclonedds
- Eclipse Zenoh ROS 2 DDS bridge: https://github.com/eclipse-zenoh/zenoh-plugin-ros2dds
- OpenCV: https://opencv.org/
- NumPy: https://numpy.org/
- Optional RealSense Python SDK: https://github.com/realsenseai/librealsense
- Modbus application protocol reference: https://modbus.org/specs.php
- Hanwha Robotics HCR/Rodi manuals are external references; the Markdown programming guides here are project notes, not vendor software or native Rodi project backups.

Dependencies retain their respective licenses. Project source attribution is recorded in [NOTICE.md](NOTICE.md).
